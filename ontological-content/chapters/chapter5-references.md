## Notes on Reference Usage

The reference numbers used in this chapter (e.g., [3], [4], [7]) correspond to the master reference list for the entire textbook as indicated in the chapter structure outline. These references provide authoritative sources for the testing procedures, specifications, and quality control requirements discussed in the chapter.

For complete test procedures, readers should obtain the current versions of referenced ASTM and AASHTO standards directly from the publishing organizations:
- ASTM International: www.astm.org
- AASHTO: www.transportation.org

State DOT specifications and FAA Advisory Circulars are typically available as free downloads from respective agency websites.
